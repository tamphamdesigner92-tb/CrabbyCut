# Đa ngôn ngữ giao diện (i18n)

CrabbyCut có 3 ngôn ngữ giao diện: **Tiếng Việt** (ngôn ngữ nguồn), **English**, **简体中文**.
Người dùng đổi ở **Menu → Cài đặt… → Chung → Ngôn ngữ giao diện**; đổi xong giao diện tải lại
(giống Premiere phải khởi động lại) và dự án đang mở được mở lại.

## Kiến trúc

| Thành phần | Tệp |
|---|---|
| Lõi `_t()`, `translateDom()`, phân giải ngôn ngữ | `static/js/i18n.js` (UMD: renderer + backend + Electron main) |
| Từ điển | `static/i18n/en.json`, `static/i18n/zh.json` — khoá = câu tiếng Việt |
| Chèn ngôn ngữ vào trang | `injectI18n()` + route `/static/i18n/:locale.js` ở `backend/server.js` |
| Tiến trình main (hộp thoại gốc, updater, Setup) | `electron/i18n-main.js` |
| Cài đặt | `general.language` = `auto` \| `vi` \| `en` \| `zh` (`static/js/app-settings.js`) |
| Kiểm tra độ phủ | `npm run i18n:check` (`scripts/i18n_check.js`) |

- **Cài mới** (chưa có `settings/app_settings.json`): `auto` → theo ngôn ngữ hệ điều hành
  (vi → Tiếng Việt, zh-* → 简体中文, còn lại → English).
- **Người dùng cũ** (có file cài đặt nhưng chưa có mục ngôn ngữ): giữ `vi`.
- "Khôi phục mặc định" **giữ** ngôn ngữ đang dùng.

## Cách viết chuỗi giao diện

Khoá là **chính câu tiếng Việt**. Ở chế độ tiếng Việt `_t()` trả lại nguyên khoá.

```js
showToast(_t('Đã lưu dự án.'));
showToast(_t('Đã xoá {n} clip', { n: count }));            // tham số: {tên}
el.innerHTML = `<h4>${_t('Chất lượng')}</h4>`;
```

1. **Không ghép chuỗi** quanh biến: `'Đã xoá ' + n + ' clip'` → `_t('Đã xoá {n} clip', { n })`.
   Thứ tự từ tiếng Anh/Trung khác tiếng Việt.
2. Câu có thẻ HTML xen giữa → để nguyên thẻ trong khoá: `_t('Nhấn <kbd>Space</kbd> để phát.')`.
   Người dịch giữ nguyên thẻ.
3. Chỉ bọc chuỗi **người dùng nhìn thấy**. KHÔNG bọc: id, khoá `data-*`, giá trị so sánh trong
   logic, khoá localStorage, tên file, log `console.*`, chuỗi gửi cho ffmpeg/ASR, regex phân
   tích kịch bản tiếng Việt, nội dung trong file `.crab`.
4. Hằng số cấp module được dịch lúc nạp — đúng, vì đổi ngôn ngữ là tải lại trang. Ở
   **backend** thì hằng số cấp module chỉ đổi ở lần mở app sau; chuỗi trả về cho người dùng nên
   gọi `_t()` **lúc dựng phản hồi**.
5. Module UMD (có thể chạy trong Node/test không có i18n) lấy `_t` có dự phòng:
   ```js
   const _t = (typeof globalThis !== 'undefined' && globalThis._t)
       || ((k, p) => (p ? String(k).replace(/\{(\w+)\}/g, (m, n) => (n in p ? p[n] : m)) : k));
   ```
6. Tiếng Anh có số nhiều: giá trị trong `en.json` có thể là `{ "one": "…{n} file", "other": "…{n} files" }`.
7. Markup tĩnh của `index.html` **không cần** bọc: `translateDom()` dịch text node và
   `title` / `placeholder` / `aria-label` / `alt` khớp nguyên văn một khoá. Câu có thẻ xen giữa
   → thêm `data-i18n-html` vào phần tử cha (khoá = innerHTML đã gộp khoảng trắng). Vùng chứa
   nội dung người dùng (tên dự án, kịch bản…) → `data-i18n-skip`.
8. Thêm chuỗi mới → thêm bản dịch vào **cả** `en.json` và `zh.json`, rồi chạy `npm run i18n:check`.

## Chính tả tiếng Việt

Bỏ dấu kiểu cũ, đang chiếm đa số trong mã nguồn: **Huỷ, xoá, tuỳ chọn, hoá, khoẻ** (không
viết Hủy, xóa, tùy, hóa). Viết hoa chữ đầu câu/nhãn, không Viết Hoa Mọi Chữ ("Xuất video",
không "Xuất Video"). Dấu ba chấm dùng ký tự "…" cho mục mở hộp thoại ("Lưu thành…").

Timeline, Keyframe, Sequence, Playhead, LUT, Codec, fps, Proxy, Clip, Block, Overlay, Preset,
SFX, Magic Fill, Auto Sound Effects, Auto-Reframe, Auto Subtitle, Local Subtitle, Match Script,
Safe Zone, Skeleton, Whisper, ASR, HQ/LQ, tên codec/định dạng (H.264, ProRes, MP4, SRT…),
CrabbyCut, Editing (tên giai đoạn).
