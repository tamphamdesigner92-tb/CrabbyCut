# Ghi công tài nguyên · Bộ tài nguyên khởi đầu CrabbyCut

Mỗi tệp trong gói có đúng một dòng dưới đây: tên trong gói, tên gốc và tác giả, link trang tải, giấy phép, ngày tải.
Ô nào còn `chưa có` thì gói chưa được phát hành. Kiểm bằng:

```bash
npm run test:starter-pack -- --dir <thư mục gói>
```

Giấy phép được nhận: **CC0 1.0** hoặc **Public Domain**; với icon, **MIT** (Tabler Icons) kèm văn bản giấy phép ở cuối tệp này;
tệp tự quay hoặc tự làm ghi "Tự làm · CrabbyCut · CC0". Không nhận Pixabay, Pexels, Mixkit (giấy phép riêng, không phải CC0, hạn chế phân phối lại tệp gốc).
